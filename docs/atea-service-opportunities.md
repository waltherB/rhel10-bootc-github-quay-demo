# Atea Service Opportunities

## Purpose

This document translates the bootc demo into sellable service concepts.

## Service 1 - RHEL Image Mode Assessment Workshop

Customer Problem:

Customers have inconsistent Linux lifecycle management, drift, manual patching and unclear rollback procedures.

Deliverables:

- Current-state assessment
- Candidate workload identification
- Image lifecycle maturity score
- Target architecture
- Adoption roadmap

Estimated Duration:

1-2 days

Business Outcome:

Customer understands where RHEL Image Mode can reduce drift and improve lifecycle control.

## Service 2 - Golden Image Factory Design

Customer Problem:

Customers need standardized OS baselines across VM, edge and platform environments.

Deliverables:

- Golden image architecture
- Containerfile patterns
- Registry design
- Signing/SBOM approach
- CI/CD workflow design
- Promotion model

Estimated Duration:

3-5 days

Business Outcome:

Customer gets a repeatable model for building and governing OS images.

## Service 3 - bootc Proof Of Concept

Customer Problem:

Customer wants to validate bootc with a real workload before adoption.

Deliverables:

- PoC repository
- bootc image build
- Quay publishing
- VM deployment
- Update and rollback demonstration
- Lessons learned report

Estimated Duration:

5-10 days

Business Outcome:

Customer has hands-on evidence and a validated adoption path.

## Service 4 - OpenShift Virtualization Image Mode Pilot

Customer Problem:

Customer is considering OpenShift Virtualization and needs a modern RHEL VM lifecycle model.

Deliverables:

- OpenShift Virtualization VM pattern
- RHEL Image Mode baseline
- GitOps-managed VM manifests
- Update/rollback model
- Pilot workload migration

Estimated Duration:

2-4 weeks

Business Outcome:

Customer gets a practical bridge between virtualization modernization and RHEL lifecycle standardization.

## Service 5 - Image Lifecycle Managed Service

Customer Problem:

Customer wants standardized image maintenance but does not want to run the entire lifecycle process alone.

Deliverables:

- Monthly image updates
- Vulnerability review
- Image promotion
- Release notes
- Rollback guidance
- Operational reports

Estimated Duration:

Recurring service

Business Outcome:

Customer receives a controlled and repeatable RHEL image lifecycle process.

## Service 6 - Platform Engineering Advisory

Customer Problem:

Customer wants to mature from manual infrastructure operations toward platform engineering.

Deliverables:

- Operating model design
- Git workflow
- CI/CD controls
- Registry governance
- Security controls
- Team enablement plan

Estimated Duration:

2-6 weeks

Business Outcome:
